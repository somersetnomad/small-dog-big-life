# Small Dog. Full Life.

A UK editorial journal for Chihuahua companions. Version three, with a full motion system.

Static site: no build step needed to serve. Source pages and the builder live in `/build` of the working environment; this repository holds the built output.

- Motion: GSAP 3.13 (ScrollTrigger, SplitText, Flip, MorphSVG, DrawSVG), served locally
- Fonts: Instrument Serif, Newsreader, Instrument Sans (self-hosted)
- No cookies, no third-party requests; optional localStorage for tool progress
- Hosting: Vercel, smalldog.noorintelligence.tech
